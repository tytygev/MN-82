управление по плюсу

лучшим решением является использование PNP биполярных транзисторов. Использование полевых (MOSFET) транзисторов здесь избыточно и усложнит схему, так как P-канальному полевику для полного открытия при 5В нужно так называемое «логическое управление» (Logic Level), а обычные копеечные транзисторы при 5В будут иметь высокое сопротивление.

Биполярный PNP-транзистор BC327-40 (в корпусе TO-92) 
или его SMD-аналог BC807-40 (в корпусе SOT-23)

Описание работы:
1.  Если ШИМ есть: Конденсатор сглаживает пульсации. Например, если ШИМ идет с заполнением 50% при 8В, то на проводе среднее напряжение будет 4В, а на пин Arduino (после делителя) придет стабильное значение около 1.28В.  
2.  Если ШИМ нет (чистый DC): Конденсатор никак не влияет на постоянный ток, схема работает точно так же, как и в прошлый раз.
3.  Защита от генерации: Стабилитрон и конденсатор работают в паре. Конденсатор берет на себя самые острые и короткие игольчатые импульсы от щеток мотора, а стабилитрон «срезает» лишнее напряжение, если мотор крутанули слишком сильно.

Датчик A3144 срабатывает на **южный полюс** магнита

Один важный нюанс, который отличает A3144 от многих других датчиков, — это **выход с открытым коллектором (open collector)**. Именно из-за него «голое» подключение может не заработать стабильно, и дело не в самом датчике, а в том, как Arduino читает его сигнал.

Внутри A3144 стоит транзистор, который соединяет выходной пин с землёй, когда видит магнит. Когда магнита нет, выход «висит в воздухе» (высокоимпедансное состояние). Чтобы Arduino могла чётко прочитать логическую единицу, этот «висящий» пин нужно **подтянуть к питанию** через резистор. Без этого пин будет ловить наводки, и `digitalRead()` может выдавать хаос вместо стабильного сигнала.

Технически, у Arduino Pro Mini есть **внутренний подтягивающий резистор** (~20–50 кОм), который включается командой `pinMode(pin, INPUT_PULLUP)` — именно эта команда уже стоит в твоём коде. **С ним датчик, скорее всего, заработает прямо на столе.** Однако внутренний резистор довольно «слабый» (высокое сопротивление), и в реальной модели, где рядом крутится мотор, искрят щётки и гуляют токи, он может не справиться с помехами. Поэтому **внешний резистор — это не обязательное, но крайне желательное усиление помехоустойчивости**.

Рекомендуемый «обвес» для датчиков стоящих на шасси рядом с силовой проводкой:
1.  Подтягивающий резистор 10 кОм между сигнальным пином и VCC 
    Это классическое решение для A3144. Он гарантирует, что в отсутствие магнита Arduino видит чёткую «1», а не наведённый шум.
2.  Керамический конденсатор 0.1 мкФ между сигнальным пином и GND
    Он работает как маленький фильтр, сглаживая высокочастотные помехи от мотора. 
	
Итоговая схема подключения для каждого датчика:
Нога 1 (VCC): к +5В.
Нога 2 (GND): к земле (GND).
Нога 3 (OUT): к пину Arduino (A1 или A2), и параллельно:
    *Резистор 10 кОм между этой ногой и +5В.
    *Конденсатор 0.1 мкФ между этой ногой и GND.

В коде команду `INPUT_PULLUP` можно оставить — она не помешает, а внешний резистор возьмёт на себя основную работу по подтяжке.

RX480-E-WQ — это компактный 4-канальный беспроводной супергетеродинный радиоприемник, работающий на частоте 433 МГц (редко 315 МГц) с поддержкой кодировки EV1527. Он принимает сигналы от пультов ДУ и выдает управляющие сигналы на четырех независимых цифровых выходах (D0–D3).
Согласование не требуется.

Характеристики и распиновка
Напряжение питания: от 3,0 В до 5,0 В постоянного тока.
Частота: 433,92 МГц (или 315 МГц).
Выходы: 4 канала (D0, D1, D2, D3) с логическим уровнем.
вывод VT (выход индикации статуса приема, выдает HIGH, когда нажата любая кнопка на пульте)
Питание и земля: контакты +V (VCC) и GND.
Антенна: контакт для припайки куска провода (обязателен для стабильного приема).

Режимы работы и настройка
Модуль поддерживает три основных режима работы, которые переключаются кнопкой обучения (Learning Key) на плате:

Импульсный режим (Inching / Momentary): сигнал на выходе D держится только пока зажата кнопка на пульте.
Настройка: нажмите кнопку обучения 1 раз, дождитесь загорания светодиода, затем нажмите кнопку на пульте.

Режим с фиксацией (Self-locking / Toggle): первое нажатие включат канал (высокий уровень), повторное — выключает.
Настройка: нажмите кнопку обучения 2 раза, затем нажмите кнопку на пульте.

Режим блокировки (Interlocking): при включении одного канала другой активный канал выключается.
Настройка: нажмите кнопку обучения 3 раза, затем нажмите кнопку на пульте.Сброс памяти: нажмите кнопку обучения 8 раз, чтобы очистить все привязанные пульты.

USB-UART на CP2102

Распиновка Pro Mini (обычно 6-контактный разъём для программирования)

• VCC – питание (5 В для вашей версии)
• GND – общий
• RXI (или RX) – вход последовательного порта (подключается к TXD адаптера)
• TXO (или TX) – выход последовательного порта (подключается к RXD адаптера)
• DTR (или GRN) – управление сбросом (если есть отдельный пин)
• RESET – можно использовать при отсутствии DTR

Подключение CP2102 → Pro Mini
```
╔════════╤══════════╤═══════════════════════════════════════════════════════╗
║ CP2102 │ Pro Mini │ Примечание                                            ║
╟────────┼──────────┼───────────────────────────────────────────────────────╢
║ TXD    │ RXI (RX) │ Передача данных от адаптера к микроконтроллеру        ║
║ RXD    │ TXO (TX) │ Приём данных от микроконтроллера                      ║
║ GND    │ GND      │ Обязательно общий провод                              ║

║ DTR    │ DTR / GRN│ Если есть выделенный пин DTR/GRN, подключайте напрямую║
```

Важно: не подключайте вывод 3V3 к 5В плате Pro Mini — это может вывести её из строя. 
Все остальные сигналы (DCD, DSR, RTS, CTS, RST, R1, SUS) не используются, оставьте их неподключёнными.
Автосброс

Для загрузки скетча Arduino IDE автоматически переключает линию DTR, что через конденсатор создаёт импульс сброса на RESET Pro Mini. Если у вас на Pro Mini есть отдельный пин DTR (часто помечен как GRN), соединение напрямую будет работать без дополнительного конденсатора, т.к. на плате уже предусмотрен конденсатор.
Если же вы подключаете DTR к RESET, обязательно поставьте конденсатор 0.1 мкФ (керамический, полярность не важна). Без него сброс может происходить некорректно или вообще не срабатывать.

> Настройка Arduino IDE
>> Подключите адаптер к USB-порту компьютера.
>> В Arduino IDE выберите:
>>> Инструменты → Плата → Arduino Pro or Pro Mini
>>> Процессор → ATmega168P (5V, 16 MHz) (или аналогичный с пометкой 168P)
>> Выберите порт, который появится в Инструменты → Порт (обычно COMx).
> Нажмите «Загрузка».

Если загрузка не удаётся
- Проверьте, что TXD адаптера соединён именно с RXI Pro Mini, а RXD — с TXO (перекрёстно).
- Убедитесь, что GND общий.
- Попробуйте нажать кнопку RESET на Pro Mini сразу после нажатия кнопки «Загрузка» в Arduino IDE (если нет автосброса).
- Проверьте, что питание 5 В подаётся на VCC Pro Mini (если плата не питается отдельно).
- Если прошивка зависает на «Uploading...», возможно, не работает DTR. Тогда вручную удерживайте RESET, запустите загрузку и отпустите RESET через пару секунд.

После этих шагов скетч должен успешно загрузиться в вашу Pro Mini.

1. Общая концепция и логика работы
Система предназначена для полного обесточивания штатной платы (XL1986RT), Arduino Pro Mini, радиоприемника (RX480-E-WQ) и DC-DC преобразователя по истечении заданного времени бездействия. 

Ключевая особенность:
Повторный запуск возможен только после перевода выключателя в положение OFF и обратно в ON. Быстрое «передергивание» (менее 0.5 сек) не сработает, если не установлен диод быстрого разряда (см. пункт 3).

Логика по состояниям:
(1) Включение (Switch ON):
    Питание 7.4В подается на Исток P-MOSFET (Q1). Конденсатор C2 разряжен, Затвор Q1 = 0В. Q1 открывается. Arduino стартует, подает HIGH на пин PIN_HOLD. Транзистор Q2 открывается и прижимает Затвор Q1 к земле, удерживая систему включенной.

(2) Рабочий режим:
    Штатная плата работает от 7.4В. Arduino и RX480 работают от 5В (DC-DC). Arduino управляет светом и моторами.

(3) Автоотключение (по таймауту): 
    Arduino подает LOW на PIN_HOLD. Q2 закрывается. Резистор R2 (1 МОм) плавно заряжает C2, подтягивая Затвор Q1 к Истоку (7.4В). Q1 закрывается. Питание 7.4В полностью пропадает со всей системы. Потребление от батареи = 0А.

(4) Сброс (Switch OFF -> ON): 
    При переводе в OFF центральный контакт кнопки соединяется с левым (GND). Исток Q1 садится на землю. Затвор Q1 (заряженный) через диод D1 мгновенно разряжается на землю. При переводе в ON система запускается с нуля.

3. Описание соединений (Pin-to-Pin)

□ Силовая часть (7.4В)
Батарея B+ -> Правый контакт выключателя (Pin 3)
Правый контакт выключателя (Pin 3) -> Исток (Source) Q1
Сток (Drain) Q1 -> Питание штатной платы XL1986RT (7.4В) + Вход Vin DC-DC
Батарея GND -> GND штатной платы, GND DC-DC, GND Arduino, GND RX480

□ Выключатель (SPDT, 3 контакта)
Правый (Pin 3) -> B+ батареи
Центральный (Pin 2) -> Исток (Source) Q1
Левый (Pin 1) -> Резистор R1 (10 кОм) -> GND

□ Узел удержания и задержки (Затвор Q1)
Затвор (Gate) Q1 -> Резистор R2 (1 МОм) -> Исток (Source) Q1
Затвор (Gate) Q1 -> Плюсовая ножка конденсатора C2 (100 мкФ). Минусовая ножка -> GND
Затвор (Gate) Q1 -> Коллектор NPN-транзистора Q2
Затвор (Gate) Q1 -> Анод диода D1
Катод диода D1 -> Исток (Source) Q1 (то есть параллельно R2)

□ Управление от Arduino
Arduino PIN_HOLD (любой цифровой пин) -> Резистор R3 (1 кОм) -> База NPN-транзистора Q2
Эмиттер NPN-транзистора Q2 -> GND

□ Питание логики (5В)
DC-DC Vin -> Сток (Drain) Q1
DC-DC GND -> GND
DC-DC 5V Out -> Arduino VCC, RX480 VCC
DC-DC En -> Перемычка на Vin (см. важное примечание 1)


4. Важные примечания для реализации

★ Защита пина En DC-DC: 
   Если ваш модуль DC-DC не рассчитан на подачу 8.4В напрямую на пин En (максимум обычно 5-6В), не соединяйте En с Vin напрямую. Поставьте делитель напряжения: резистор 10 кОм от Vin к En и резистор 20 кОм от En к GND. Это снизит напряжение на En до безопасных ~5.6В при полном заряде батареи.

★ Логика скетча Arduino:
   *В блоке setup(): Сразу подать HIGH на PIN_HOLD (чтобы удержать питание после загрузки).
   *В блоке loop(): Отслеживать таймер бездействия. При достижении таймаута подать LOW на PIN_HOLD.

★ Нагрев Q1:
   IRF9Z34N рассчитан на ток до 19А. Если моторы потребляют большой ток (например, при заклинивании), MOSFET может греться. Рекомендуется установить небольшой радиатор

★ Диапазон напряжений:
   Схема работоспособна от 4В до 9В. При 4-5В убедитесь, что DC-DC справляется с выдачей 5В и 300 мА. При 8-9В следите за нагревом DC-DC и защитой пина En.

Логика архитектуры
	Интерфейс и конфигурация
		Класс PowerManager
			В конструкторе класса предусмотрена передача всех пинов и их активных уровней
			Неограниченное количество пинов с разными уровнями: реализуем через передачу массива структур InputPin в конструктор.		
			Время таймаута в миллисекундах.

	Реализация логики ввода/вывода
		Метод инициализации begin() — настраивает пины и сразу подает активный уровень на PIN_HOLD для фиксации питания.
		Метод update() — вызывается в основном цикле loop(). Он будет опрашивать входы. Если зафиксирован активный сигнал (с учетом заданного уровня), таймер сбрасывается.

	Логика таймера и состояния 
		Внутренний учет времени через millis().
		Если в течение заданного времени update() не фиксирует активности, класс переходит в состояние подготовки к выключению.
		Реализация метода shutdown() — переводит пин удержания в неактивный уровень (LOW) и, при необходимости, вызывает пользовательский коллбэк.

	Структура файлов (Разделение для переиспользования)
		PowerManager.h — декларация класса, интерфейсы, конфигурация.
		PowerManager.cpp — реализация методов, работа с millis(), чтение пинов и управление выходом.
		В основном .ino файле создание экземпляра класса с нужными настройками и вызов двух методов: power.begin() в setup() и power.update() в loop().

пример использования: 

#include "PowerManager.h"

// Настройки пинов
#define PIN_HOLD D13
#define PIN_RC   D12
#define PIN_HALL_1 A1
#define PIN_HALL_2 A2

// Конфигурация входов
// 1. RC-модуль: активный HIGH, обычный INPUT
// 2. Датчики Холла: активный LOW, INPUT_PULLUP (чтобы не висел в воздухе)
const InputPin inputs[] = {
  {PIN_RC,     HIGH, INPUT},
  {PIN_HALL_1, LOW,  INPUT_PULLUP},
  {PIN_HALL_2, LOW,  INPUT_PULLUP}
};
const uint8_t inputCount = sizeof(inputs) / sizeof(inputs[0]);

// Настройки питания: удержание HIGH на D13, таймаут 5 минут (300000 мс)
PowerManager power(PIN_HOLD, HIGH, inputs, inputCount, 300000);

// (Необязательно) Коллбэк для выполнения перед выключением
void onPowerOff() {
  // Например, выключить свет или мигнуть фарами
  // digitalWrite(PIN_LIGHTS, LOW);
}

void setup() {
  // Инициализация менеджера питания должна быть ПЕРВОЙ
  power.setShutdownCallback(onPowerOff);
  power.begin();

  // ... остальная инициализация ...
}

void loop() {
  // Опрос датчиков и таймера
  power.update();

  // ... основной код ...
}
